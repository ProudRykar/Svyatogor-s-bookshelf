# Книгохранилище Святогора 📜

**Книгохранилище Святогора** — это консольное приложение для учёта и хранения книг, пропитанное духом славянских сказаний и мудростью богатыря Святогора. Проект позволяет управлять библиотекой записей, используя команды на старославянском стиле, такие как `ПРИЛОЖИ`, `ОБРЕСТИ` и `ИЗЫМИ`.

## Особенности

- **Славянский интерфейс**: Команды вроде `ПРИЛОЖИ` (добавить), `ОБРЕСТИ` (найти), `ИЗЫМИ` (удалить) и `ПЕРЕЧЕНЬ` (список) погружают в атмосферу древнерусских летописей.
- **Хранение данных**: Записи о книгах (ID, имя, значение) сохраняются в бинарном файле с шифрованием XOR для защиты данных.
- **Гибкий поиск**:
  - По ID (`ОБРЕСТИ <номер>`).
  - По имени (`ОБРЕСТИ <имя>`).
  - По значению (`ОБРЕСТИ_ЗНАЧЕНИЕ <значение>`).
  - По диапазону значений (`ОБРЕСТИ_ДИАПАЗОН >мин<макс`, `больше <мин> и меньше <макс>`, `больше <число>`, `меньше <число>`, `>число`, `<число>`).
- **Логирование**: Поддержка четырёх режимов логирования (без логов, в файл, в консоль, оба варианта) с временными метками и длительностью операций.
- **Анализ запросов**: Команда `АНАЛИЗ` предоставляет информацию о производительности и использовании индексов.
- **Поддержка UTF-8**: Корректное отображение кириллических символов с учётом их ширины в консоли.

## Как работает?

- **Структура данных**: Используются две таблицы — `Names` (имена книг) и `Records` (записи с ID, name_id и значением). Индексы (`unordered_map` и `map`) обеспечивают быстрый поиск по ID и имени.
- **Шифрование**: Данные шифруются с помощью XOR с использованием ключа (`mysecretkey`).
- **Логика поиска**:
  - Поиск по ID и имени — O(1) благодаря хэш-таблицам.
  - Поиск по значению или диапазону — O(n), так как требует полного сканирования.
- **Логирование**: Время выполнения запросов фиксируется в консоли и/или файле `application_log.txt`.

## Установка и запуск

### Требования
- Компилятор C++ (поддерживающий C++11 или выше, например, `g++`).
- Операционная система: Linux, macOS или Windows (с поддержкой UTF-8 в консоли).

### Инструкции
1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/<your-username>/Svyatogor-Book-Storage.git
   cd Svyatogor-Book-Storage
   ```
2. Скомпилируйте программу:
   ```bash
   g++ -std=c++11 main.cpp database.cpp -o database
   ```
3. Запустите приложение:
   ```bash
   ./database
   ```
4. Выберите режим логирования (0–3) и начните работу с командами.

## Текущие ограничения
- Поиск по значению и диапазону выполняется с полным сканированием (O(n)), что может быть медленно для больших баз данных.
- Отсутствует поддержка отрицательных чисел в команде `ОБРЕСТИ_ДИАПАЗОН` с форматами `>число` и `<число` из-за ограничений регулярных выражений.
- Нет графического интерфейса — только консольное взаимодействие.

## История Книгохранилища

В стародавние времена, когда на Руси богатыри землю стерегли, жил да был Святогор, силач столь могучий, что горы под ним дрожали. Но не только мечом да копьём славен был Святогор — разум его был остёр, а сердце полно любви к мудрости и книгам. Велел он собрать все летописи, сказания и песни земли русской, дабы сохранить их для потомков.

Однако не простым было то хранилище. Злой змей, прозванный Хаосом, пытался записи те разорить: имена книг путал, числа их ценности терял, а то и вовсе летописи стирал. Долго бился Святогор с Хаосом, но змей был хитер и неуловим. Тогда призвал богатырь мастеров земли русской — кузнецов кодов и хранителей данных. Те, взяв железо C++ да молоты алгоритмов, выковали Книгохранилище — твердыню, где каждая книга имела свой номер, имя и ценность.
